03 / Integration notes

A few things to know.

How accurate is the hosted clock?

The main website explains its server-time comparison and network uncertainty. Read Is your clock right? for how it works and what the measurement can tell you.

Can I style or control the clock from my page?

You can style the iframe container and set its height. The content belongs to another origin, so your page cannot reach into its DOM or control its settings. Use the controls inside the hosted page. The theme button here changes this documentation page only.

What if my site blocks the iframe?

If your site has a Content Security Policy, its frame-src directive must allow https://www.onlinedigitalclock.com. A browser extension, network filter, or future host policy may also prevent embedding. Keep a direct clock link beside the frame. An iframe load event alone does not prove the clock rendered successfully.

Does the embed work offline or collect information?

The frame needs internet access and runs the hosted website, whose privacy policy applies. This examples page adds no analytics or account sign-in. Framed pages may have their own cookies, analytics, and advertising.

Where can I install the Chrome extension?

Use the published Digital Clock Online Chrome Store listing. See extension details for features and privacy. This repository does not distribute an extension.

What source code is public?

This repository contains only newly written documentation, iframe examples, and this static page. The production website and browser extension source remain private. The example files are available under the repository’s MIT license.
